# Francisco Dutra — Portfolio

Personal portfolio. Single `index.html`, no build, no dependencies.

**AI Automation Engineer & Developer** — based in Argentina, open to remote work.

## Features

- Single self-contained HTML file (all CSS + JS inline)
- Fully responsive (mobile first)
- Light / dark mode toggle (persisted)
- English / Spanish toggle (auto-detects browser language, persisted)
- Smooth scroll, intersection-observer reveal animations
- `prefers-reduced-motion` respected
- Zero external runtime dependencies (only Google Fonts)

## Stack on display

Python · PostgreSQL · Docker · n8n · Vercel · Streamlit · Scikit-learn · Gemini API · Claude API · SQL Server · Selenium · Git

## Deploy

### GitHub Pages
1. Push to a public repo (or name the repo `frandutra.github.io` for the root URL).
2. Settings → Pages → Source: `main` / `/ (root)` → Save.
3. Live at `https://<user>.github.io/<repo>/`.

### Vercel
1. Import the repo on [vercel.com](https://vercel.com).
2. Deploy — no build settings needed.

## Local

Just open `index.html` in a browser. Or:

```bash
python3 -m http.server 8000
```
